# How do I interpret user needs and incorporate them into a program?
The user needs are the requirements for a program. Knowing what is needed, such as the length requirement for a password or what an acceptable format of an address would consist of. You write those requirements into the code, and then ensure they perform properly using JUnits tests. Testing invalid and valid forms of input make sure that the requirements are met.
